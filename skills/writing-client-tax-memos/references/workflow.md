# Client memo workflow

## Input gate

Require:

- CPA-approved workpaper or conclusion
- exact client facts and tax year
- approved calculation and counterfactual, if used
- current authority for the rule
- known open items
- requested client action
- voice examples when the CPA has a preferred style

An approved source can still contain an open item. State the open item instead of completing it with an assumption.

## Memo shape

1. State the result in the first paragraph.
2. State the client facts that control the result.
3. Explain the rule in plain words.
4. Show the calculation with only the needed numbers.
5. Name any open issue and its effect.
6. Give a conditional planning note supported by the approved workpaper.
7. Ask for the exact next action or document.
8. List the main authority links when useful to the client.

## Voice

Use short sentences and ordinary words. Keep the tone calm when the result disappoints the client. State what the CPA can confirm now and what still needs review. Avoid sales language, broad promises, and internal process terms.

## Fact check

Create one row for every controlling fact, amount, percentage, threshold, rule, form, and planning condition. A claim needs an approved status and a workpaper reference. A rule also needs a current authority URL.
