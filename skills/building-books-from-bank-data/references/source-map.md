# Source map

Accessed August 24, 2026.

- Randy Keller and Amir Curry, `opulent-cpa-workflow-explainer.md`. Workflow B defines the books-from-nothing case and required artifacts.
- [IRS Publication 583](https://www.irs.gov/publications/p583). Use for business records, journals, ledgers, supporting documents, and bank reconciliation context.
- [APEX Accounting dataset](https://huggingface.co/datasets/mercor/apex-accounting) and [leaderboard](https://www.mercor.com/apex/apex-accounting-leaderboard/). Use the synthetic-company world, multi-file reconciliation, golden response, and one-outcome-per-criterion patterns.
- [Shortcut accounting use cases](https://shortcut.ai/cases/how-accounting-teams-use-shortcut) and [case library](https://shortcut.ai/cases). Use GL mapping, trial-balance cross-reference, validation flags, and manager review as examples only.
- [Opulent knowledge-work demo suite](https://github.com/OpulentiaAI/knowledge-work-demo-suite). Use immutable source workspaces, exact deliverables, provenance, and local validators.
- [Harbor evals](https://www.harborframework.com/docs/run-jobs/run-evals). Use instruction, environment, and test script as the evaluation unit.
- [OSWorld](https://osworld-v1.xlang.ai/). Use when testing visible QuickBooks or spreadsheet work and preserve trajectories.
- [Letta creating-skills](https://github.com/letta-ai/letta-code/tree/main/src/skills/builtin/creating-skills) and [Matt Pocock writing for agents](https://github.com/mattpocock/skills/tree/main/skills/productivity/writing-for-agents). Use for the skill package, progressive disclosure, evidence fields, and completion checks.
- [Financial Datasets](https://www.financialdatasets.ai/) and [CWU economic and financial datasets guide](https://libguides.lib.cwu.edu/c.php?g=358343&p=2419792). Use only for separate public-data fixtures. Neither source supplies client bookkeeping facts.
