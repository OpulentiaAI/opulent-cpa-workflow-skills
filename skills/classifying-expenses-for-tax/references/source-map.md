# Source map

Accessed August 24, 2026.

## Workflow authority

- Randy Keller and Amir Curry, `opulent-cpa-workflow-explainer.md`. Workflow A supplies the input, output, exception, and human-review contract.
- [2025 Schedule C instructions](https://www.irs.gov/instructions/i1040sc). Use for current 2025 expense labels, line placement, and vehicle reporting.
- [IRS Publication 583](https://www.irs.gov/publications/p583). Use for recordkeeping, ledgers, source documents, and reconciliation.

## Skill and evaluation construction

- [Letta creating-skills](https://github.com/letta-ai/letta-code/tree/main/src/skills/builtin/creating-skills). Use for concise SKILL.md files, progressive disclosure, scripts, references, assets, and packaging.
- [Matt Pocock writing for agents](https://github.com/mattpocock/skills/tree/main/skills/productivity/writing-for-agents). Use for clear triggers, completion criteria, evidence boundaries, and forward tests.
- [Harbor evals](https://www.harborframework.com/docs/run-jobs/run-evals). Use the instruction, environment, and test-script task shape.
- [APEX Accounting dataset](https://huggingface.co/datasets/mercor/apex-accounting) and [leaderboard](https://www.mercor.com/apex/apex-accounting-leaderboard/). Use realistic accounting worlds, hidden input manifests, golden outputs, and self-contained outcome criteria.
- [OSWorld](https://osworld-v1.xlang.ai/). Use trajectory review when the task requires visible spreadsheet or accounting-software work.
- [Opulent knowledge-work demo suite](https://github.com/OpulentiaAI/knowledge-work-demo-suite). Use immutable sources, declared deliverables, rubrics, provenance, and validators.

## Example and data sources

- [Shortcut accounting cases](https://shortcut.ai/cases/how-accounting-teams-use-shortcut) and [case library](https://shortcut.ai/cases). Use the review-flag and reconciliation patterns as product examples only.
- [Financial Datasets](https://www.financialdatasets.ai/). Use only when a task needs public-company market or filing data. It is not a source for client tax treatment.
- [CWU economic and financial datasets guide](https://libguides.lib.cwu.edu/c.php?g=358343&p=2419792). Use as a directory for public sample data such as BEA, FRED, BLS, OECD, and World Bank sources.
