# Worked synthetic example

## Scenario

A physician starts a Schedule C consulting business. Discovery notes mention a self-directed retirement plan, a vehicle purchase, Arizona work, a home office, and a hacked business account.

## Result

The baseline asks for income forms, business account statements, expense records, asset documents, and estimated-tax records. The addendum asks for the plan records, mileage log and purchase agreement, state workday support, home-office facts, and fraud-loss evidence.

Every addendum row carries the cue ID from `assets/sample-input/client_profile.json`. The traceability file identifies the source note for every request.
