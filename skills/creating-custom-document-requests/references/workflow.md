# Custom document request workflow

## Inputs

Use the engagement letter or scope, client profile, discovery notes, prior return, current-year facts, supplied-document inventory, and CPA style examples. Record the tax year and requested period explicitly.

## Baseline stage

Create the professional-standard request for the entity and return types. Organize by topic and keep each item specific. Include the reason internally even when the client draft omits it.

## Addendum stage

Extract cues such as a new entity, asset purchase, vehicle, home office, retirement plan, work in another state, property transaction, unusual loss, payroll, contractors, charitable activity, dependent change, or prior notice. Give each cue a stable ID and source location.

Turn each cue into a request that can resolve an eligibility element, amount, timing, source, ownership, substantiation, or form question. Ask for a fact when no document exists.

## Quality checks

- baseline and addendum are separate
- every item has a period
- every custom item traces to a cue
- each request asks for one clear thing
- supplied documents are removed
- duplicates are removed
- sensitive data is requested only when needed
- secure delivery is named
- the CPA approves before delivery

## Style adaptation

Use prior request lists for order, terms, greeting, and level of detail. Keep current client facts authoritative. Preserve the CPA's method without carrying another client's names, amounts, dates, or special requests into the draft.
